# 🎨 Saraçoğlu Dekorasyon - Profesyonel Web Sitesi

Saraçoğlu Dekorasyon şirketinin modern, responsive ve profesyonel web sitesi.

## 📋 Proje Özellikleri

### Sunulan Hizmetler
- 🎨 **Dekoratif Boya** - Modern ve klasik boya çeşitleri
- 📐 **Dekoratif Alçı** - Tavan ve duvar tasarımı
- 🏗️ **Kartopiyer Uygulaması** - Düz ve kurvilineer tasarımlar
- 🔧 **Asma Tavan Sistemi** - Akustik ve dekoratif çözümler
- 🏢 **Dış Cephe Tasarımı** - Bina cephe yenileme

## 🎨 Özelleştirme

### Renkler Değiştirme
CSS dosyasında `:root` bölümünü düzenleyin:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #e74c3c;
    --accent-color: #3498db;
}
```

### İçerik Güncelleme
HTML dosyasında ilgili bölümleri düzenleyin.

### Görselleri Değiştirme
Unsplash URL'lerini kendi görselleriyle değiştirin.
